# Site Diagnostics

Локальный однопользовательский сервис экспресс-диагностики интернет-магазинов. По адресу сайта сервис определяет стек, собирает технические факты, проверяет страницы в headless Chrome, использует ИИ для интерпретации результатов и формирует технический или клиентский отчёт.

## Стек

- PHP 8.x, MySQL 8, PDO;
- собственный Mini-MVC без фреймворка;
- Tabler для интерфейса, Vanilla JS;
- `chrome-php/chrome` для браузерных проверок и PDF;
- PHPUnit для тестов;
- Windows + OpenServer, локальный запуск без публикации в интернете.

## Структура

```text
public/          Document root и единственная точка входа
src/Controllers/ Обработка HTTP-запросов
src/Models/      Работа с БД
src/Views/       PHP-шаблоны и компоненты
src/Services/    Диагностика, браузер, ИИ, отчёты и внешние сервисы
src/Core/        Роутер, БД, запросы, логирование и общие функции
config/          Настройки, маршруты и промпты ИИ
bin/             Фоновый воркер и служебные команды
data/            Сигнатуры, селекторы и справочники
storage/         Логи, кэш, скриншоты, PDF и временные файлы
tests/           PHPUnit-тесты
.docs/           PRD, схема БД, фазы, DoD и журнал разработки
```

## Запуск и проверка

1. Настроить локальный сайт OpenServer с document root `public/`.
2. Создать `.env` по `.env.example`.
3. Выполнить `composer install`.
4. Подготовить БД по `database/install.php` и `.docs/database.md`.
5. Запустить проверки: `composer test`.

Секреты хранятся только в `.env` и не попадают в репозиторий, отчёты или логи.

## Разработка с агентом

Главный регламент: `AGENTS.md`. Он определяет автономный цикл: изучение контекста, реализация, проверка и обновление статусов. Копировать промпты вручную не нужно.

- `TASK.md` — текущая задача, Scope и DoD;
- `.docs/phases/_status.md` — состояние фаз и проектные решения;
- `current-pipeline.md` — краткое описание процесса;
- `.claude/rules/general.md` — общие правила;
- `.claude/rules/php.md` — обязательные правила PHP;
- `.claude/rules/design.md` — обязательные правила дизайна и UI;
- `.docs/dod-global.md` — глобальная готовность.

`CLAUDE.md` сохранён как совместимая ссылка на `AGENTS.md`.
