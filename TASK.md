# Current Task

## Фаза
Phase 2 — Глубокая проверка и история

## Задача
Стек определяет версию OpenCart по отпечаткам публичных статических файлов (хэш файла → версии релизов), чтобы
ядро OpenCart сверялось с актуальной версией (`outdated`) и с NVD / OSV (`vulnerability`).

## Образец
Образца нет: компоненты Tabler (решение владельца, 15.11.2026). Экран не меняется: версия и её источник выводятся
существующим компонентом стека («Источники признака»).

## Почему (найдено в таске 9, проверено 16.11.2026)
- У сигнатуры OpenCart нет источника версии: ни meta generator, ни служебного файла.
- Подвал входа в админку (`/admin/`) версию без входа не показывает (OpenCart 2.x / 3.x / ocStore / OPENCART.PRO —
  проверено вживую).
- Публичные файлы ядра меняются от релиза к релизу. Хэши по 50 тегам GitHub `opencart/opencart`: `admin/view/javascript/common.js` — 21 вариант,
  `admin/view/stylesheet/stylesheet.css` — 21, `catalog/view/javascript/common.js` — 18. Пересечение по нескольким
  файлам на витрине opencart.com: из 25 магазинов 4 — точная версия (3.0.3.8 ×2, 4.1.0.4 ×2), 8 — диапазон
  (3.0.3.3–3.0.3.7, 2.3.0.0–2.3.0.2 …), остальные — файлы изменены / закрыты.

## Решения
- **Отпечатки:** `data/fingerprints/opencart.json` — путь файла → md5 содержимого (переводы строк `\r\n` → `\n`,
  без BOM) → версии. Генерирует `php bin/build-opencart-fingerprints.php` (теги GitHub API + файлы
  raw.githubusercontent.com); запускается вручную при выходе нового релиза. Неизвестный релиз — хэш не совпадёт,
  версии нет (без ошибки).
- **Файлы:** `admin/view/javascript/common.js`, `admin/view/stylesheet/stylesheet.css`,
  `catalog/view/javascript/common.js`, `catalog/view/theme/default/stylesheet/stylesheet.css` (2.x / 3.x),
  `catalog/view/stylesheet/stylesheet.css` (4.x).
- **Сопоставление:** только ответы 200 без обрезки; хэш не из базы (файл изменён, тема своя, страница защиты от
  ботов) — файл не учитывается; версии — пересечение по совпавшим файлам.
  - одна версия → версия OpenCart (сильный признак, как служебный файл);
  - несколько → версии нет (лучше пропустить, чем ошибиться), в «Источниках признака» — «отпечатки файлов:
    3.0.3.3–3.0.3.7, точная версия не определена»;
  - пересечение пустое (файлы разных релизов) → версии нет.
- Отпечатки запрашиваются только для найденной CMS без версии, после `probes` (как у Joomla). Общий механизм:
  ключ `fingerprints` у платформы в `data/signatures.php` — имя файла в `data/fingerprints/`.
- ocStore / OPENCART.PRO (сборки OpenCart) — те же файлы ядра совпадают с релизами OpenCart: версия — версия
  OpenCart, на которой собрана сборка.
