# Current Task

## Фаза
Phase 2 — Глубокая проверка и история

## Задача
На главной форме появляется необязательное поле «Адрес товара»: адрес проверяется так же, как ссылка на сайт,
должен вести на тот же сайт и сохраняется в `diagnostics.product_url`; в отчёте он виден в сводке.

## Образец
Образца нет: компоненты Tabler (решение владельца, 15.11.2026). Изменения экранов:
- **форма** (`/`): поле «Адрес товара (необязательно)» между «Ссылка на сайт» и «Описание проблемы»,
  оформлено как поле ссылки: подсказка, ошибка у поля (`is-invalid` + `invalid-feedback`), ввод сохраняется
  после ошибки;
- **отчёт**: в карточке «Сводка» строка «Адрес товара (указан вручную)», если он задан; видна, даже когда
  сводки доступности нет.

## Решения (15.11.2026, подтверждены владельцем)
- Хост адреса товара (без `www.`) должен совпадать с хостом сайта; поддомен (`catalog.shop.ru` при `shop.ru`)
  не принимается — тогда сайт указывается как `catalog.shop.ru`
- Адрес главной (путь `/` без параметров) вместо товара отклоняется с подсказкой «Укажите страницу товара»

## Заметки по реализации
- Адрес товара может быть и на `http://`, если сайт на `https://` (и наоборот): сравнивается только хост без `www.`
- Товар через параметры на главной (`shop.ru/?product_id=42`) принимается: «главная» — только путь `/` без параметров
- Сообщения о формате (схема, логин/пароль, разбор) общие с полем «Ссылка на сайт» (`normalizeSiteUrl()`)
- В тесте `testValidateDiagnosticInputKeepsValuesOnError` добавлено поле `product_url` (значения формы сравниваются целиком)
