# Current Task

## Фаза
Phase 3 — Проверка в браузере

## Задача
Воркер запускает Chrome без окна (`chrome-php/chrome`), открывает каждую проверенную страницу с тайм-аутом и
гарантированно закрывает браузер; путь к Chrome задаётся на странице настроек, там же кнопка «Проверить Chrome».
Без Chrome шаг `browser` — `skipped` с причиной, отчёт строится.

## Образец
Образца нет: компоненты Tabler (решение владельца, 15.11.2026). На странице настроек — отдельная карточка
«Браузер» (поле пути + кнопки «Сохранить» и «Проверить Chrome») под карточкой «Ключи API (.env)» в правой колонке.
Отчёт не меняется: шаг `browser` виден в существующем списке шагов и в «Не удалось проверить».

## Окружение (проверено 16.11.2026)
- Google Chrome 157 — `C:\Program Files\Google\Chrome\Application\chrome.exe`
- PHP 8.3.6 OpenServer (и CLI воркера, и сайт — `php_engine = PHP-8.3` в `.osp/project.ini`), `sockets` включён
- `chrome-php/chrome` v1.16.2: PHP `^8.0.2`, зависимости `symfony/process`, `symfony/filesystem`, `chrome-php/wrench`

## Решения
- **Путь к Chrome:** настройка `settings.chrome_path`. Пустая → константа `CHROME_DEFAULT_PATH`
  (`C:\Program Files\Google\Chrome\Application\chrome.exe`). Валидация поля: абсолютный путь Windows
  (`C:\…`), файл `.exe`, без кавычек и переводов строк, до 255 символов. Существование файла проверяет кнопка
  «Проверить Chrome» и сам шаг, а не валидация (путь можно сохранить заранее).
- **Форма:** отдельная форма `POST /settings/browser` (CSRF, redirect). «Сохранить» — сохраняет путь;
  «Проверить Chrome» (`name="action" value="check"`) — сохраняет и запускает Chrome. Результат — flash:
  «Chrome 157.0.… работает» или понятная ошибка (файл не найден / не запустился / не ответил за N с).
  Ошибка валидации → поле подсвечено, ввод сохраняется (как у формы моделей), путь не сохраняется.
- **Версия Chrome** — через DevTools (`Browser.getVersion`) после запуска, а не `chrome.exe --version`:
  на Windows `--version` ничего не печатает.
- **Тайм-ауты** — константы: запуск браузера 30 с, загрузка страницы 30 с; проверка из веба — 15 с
  (`CHROME_CHECK_TIMEOUT`, меньше `max_execution_time` веб-запроса).
- **Параметры запуска:** без окна, окно 1366 × 768, `ignoreCertificateErrors` (проблемы SSL уже ловит
  `SslCheck`, страница всё равно должна открыться), отдельная папка профиля. User-Agent — собственный у Chrome,
  не подменяется.
- **Профиль:** на каждый запуск — новая папка `storage/temp/chrome-<diagnostic_id>-<случайное>/` (`storage/temp/*`
  уже в `.gitignore`). В `finally` — закрыть браузер, удалить папку (несколько попыток с короткой паузой: Windows
  держит файлы ещё мгновение после закрытия). Перед запуском — удалить папки `chrome-*` старше суток
  (остались от убитого воркера; суток хватает, чтобы не задеть параллельную диагностику).
- **Шаг `browser`** «Проверка в браузере» — после `seo`. Страницы — из фактов `availability` (главная) и `crawl`
  (найденные); если `crawl` не выполнился — только главная. Не открываются: страницы с защитой от ботов
  (`bot_protection` / `blocked`) и страницы без ответа (`status = null`). Каждая страница открывается на 1366,
  в факты: `opened` / `timeout` / `error`, время загрузки, текст ошибки. Heartbeat — после каждой страницы.
  Не открылась одна страница — идём дальше. Сообщение шага: «Открыто в браузере: 4 из 5 страниц (пропущено: 1 —
  защита от ботов)». Нет ни одной страницы для браузера → `skipped` с причиной. Chrome не запустился / нет
  `vendor` → `skipped` с причиной. Находок шаг в этом таске не создаёт.
- **Composer:** `chrome-php/chrome` `^1.16` в `require`; `config.platform.php = 8.3.6`, чтобы composer не выбрал
  зависимости под более новый PHP (`symfony/*` 8.x требуют PHP 8.4), даже если сам composer запущен другим PHP.
  `vendor/autoload.php` подключается в `config/config.php` только если файл есть — без `vendor` сайт работает,
  а шаг `browser` пропускается с причиной «не выполнен composer install».
- **Стиль:** `BrowserService.php` — функции (как остальные сервисы); объекты `chrome-php` используются только
  внутри него. Чистые функции (валидация пути, параметры запуска, отбор страниц, сообщение шага) — отдельно от
  функций, которые запускают Chrome, чтобы их покрыть тестами без браузера.
