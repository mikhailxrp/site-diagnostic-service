## Почему (найдено при проверке таска 7, 16.11.2026)
- wpbeginner.com: wpforms определён как 1.21.0 — `?ver=` встроенной библиотеки
  `wpforms/assets/lib/jquery.validate.min.js?ver=1.21.0`; настоящая версия — `wpforms.min.js?ver=2.0.3` →
  ложная уязвимость «WPForms Pro <= 2.0.0.2». Причина: `addStackSignal()` берёт версию первого файла.
- Библиотека в папке темы / плагина (`/wp-content/themes/x/js/swiper.min.js?ver=1.0`) получает `?ver=` темы →
  «Swiper 1.0» → ложные устаревание и уязвимости.
- jQuery 2.2.4: 6 отдельных находок, одна из них — «1.x / 2.x End-of-Life» (дубль находки `outdated`).
- Уязвимости «Authenticated (Administrator+)» снаружи не эксплуатируются, а серьёзность — как у остальных.

## Решения
- **Версия ассетов — голосованием** (только темы / плагины / библиотеки; версия из meta generator, служебного
  файла, заголовка — как сейчас, первая):
  - файл темы / плагина в папке библиотек (`/lib/`, `/libs/`, `/vendor/`, `/vendors/`, `/node_modules/`,
    `/bower_components/`, `/third-party/`, `/external/`) или файл известной библиотеки (сигнатуры `libraries`,
    `jquery.*.js`) — версию не даёт;
  - файл с именем плагина / темы (`wpforms.min.js`) — вес 2, остальные файлы — вес 1;
  - библиотека: версия в имени файла / пути — вес 2; `?ver=` — вес 1, а в папке темы / плагина CMS — не
    учитывается;
  - побеждает версия с наибольшим весом; ничья разных версий → версия неизвестна (лучше пропустить, чем ошибиться).
- **Шаг `vulnerabilities`:**
  - элементы стека с уверенностью `low` не сверяются;
  - записи «End-of-Life / no longer supported» (retire.js) — не уязвимость, пропускаются (это находка `outdated`);
  - роль из названия записи Wordfence: Administrator+ / Editor+ / Shop Manager+ / Super Admin → не выше `low`;
    Author+ / Contributor+ → на ступень ниже; Subscriber+ / Customer+ — без изменений (в магазинах покупатели
    регистрируются). В тексте — «для атаки нужен вход с ролью …»;
  - тема с общим именем (`theme`, `main`, `default`, `custom`, `child`, `site`, `shop`, `store`, `starter`,
    `base`, `new`, `template`) не сверяется — риск совпасть с чужой темой каталога;
  - одна находка на элемент стека: заголовок «jQuery 2.2.4: 5 уязвимостей (CVE-…, …)», серьёзность — наибольшая,
    «обновить до» — наибольшая из исправленных версий; в тексте и в `evidence.vulnerabilities` — каждая уязвимость с
    идентификатором, диапазоном, исправленной версией, CVSS и ссылкой.
