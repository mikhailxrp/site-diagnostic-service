# Current Task

## Фаза

## Задача
Страница `/settings`: владелец задаёт модели RouterAI для трёх ИИ-задач (сохраняются в `settings`),
ключи API и base URL из `.env` показываются только для чтения (маской).

## Образец
Образца нет — экран собирается из стандартных компонентов Tabler без своих стилей (решение владельца,
15.11.2026): `card` с группами полей, `form-control` / `is-invalid` / `invalid-feedback`, `datagrid`
для ключей.

      - `getAllSettings(): array` — ключ → значение;
      - `getSetting(string $key): ?string`;
      - `saveSettings(array $values): void` — `INSERT … ON DUPLICATE KEY UPDATE` одной транзакцией,

- [x] `src/Services/SettingsService.php` — создать:

        `model_summary`);
