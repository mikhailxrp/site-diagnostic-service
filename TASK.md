# Current Task

## Фаза
Phase 1 — Экспресс-диагностика

## Задача
Завершённая диагностика (`done`) показывает отчёт, а упавшая (`failed`) показывает частичный отчёт из того, что
успело собраться. В отчёте: сводка доступности и SSL, стек с раскрываемыми источниками признаков, находки по
серьёзности и шаги, которые не удалось проверить.

## Образец
Образца нет: экран собирается из стандартных компонентов Tabler (решение владельца, 15.11.2026),
без своих стилей. Состояния экрана:
- **готово, есть находки**: сводка, стек, находки по группам серьёзности со счётчиками;
- **готово, находок нет**: в блоке находок пустое состояние Tabler `empty` с текстом «Проблем не найдено»;
- **стек не определён**: «Стек определить не удалось» вместо пустой таблицы;
- **шаги `failed` / `skipped`**: блок «Не удалось проверить» с названием шага и причиной (`message`);
- **ошибка (`failed`)**: алерт об ошибке, как сейчас, под ним частичный отчёт с пометкой «Отчёт неполный:
  диагностика прервана»; блоки без данных показывают свои пустые состояния;
- **идёт проверка**: как сейчас (прогресс). По `done` / `failed` страница перезагружается и показывает отчёт.

## Решения (15.11.2026, подтверждены владельцем)
- Раскрытие источников стека и сырых данных находки: нативный `<details>/<summary>`, JS Tabler/Bootstrap
  не подключается (в `admin/layout/footer.php` его нет)
- При `failed` выводится частичный отчёт: то, что успело записаться в БД (`summary_json`, `stack_items`,
  `findings`, `checked_pages`)
- Сырые `evidence` находки показываются форматированным JSON в раскрывающемся блоке

## Отклонения и заметки по реализации
- Блок `data-result-done` переименован в `data-result-report`: он показывается и при `done`, и при `failed`
- Компоненты подключаются через `render('components/…')`, как уже сделанный `flash.php`
- Заголовки групп (`list-group-header`) стоят внутри списка как `<li role="heading" aria-level="3">`: вне
  `.list-group` у Tabler пропадают отступы
- `cancelled` в коде нигде не выставляется, поэтому отчёт для него не делался
- Браузер может держать в кэше старый `diagnostic-progress.js`: после обновления один раз нажать Ctrl+F5
- Разово (1 раз из ~30 запросов) Apache/PHP 8.3 отдал `Fatal error: Maximum call stack size … during
  compilation` в `public/index.php:3` ещё до кода проекта. Похоже на баг PHP 8.3 на Windows с определением
  стека; к таску не относится
