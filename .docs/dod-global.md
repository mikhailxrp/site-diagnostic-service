# Global Definition of Done

Эти критерии применяются к каждому таску и отдельной доработке.
Разделы, которых задача не касается, пропускай и явно указывай это в итоге проверки.

---

## UI
- [ ] Страница открывается без ошибок и сломанной вёрстки
- [ ] Проверены ширины **360 px**, **768 px** и **1280 px**: нет горизонтальной прокрутки, длинные значения переносятся
- [ ] Интерактивные элементы (кнопки, ссылки действий) имеют зону нажатия не меньше **44 px**
- [ ] Обработаны применимые состояния: пустое, ошибка, частичный отчёт (`failed`), загрузка/прогресс
- [ ] Интерфейс собран из стандартных компонентов Tabler без inline-стилей и лишнего CSS; если экран экспортируется в PDF — проверен режим `$isPdfExport` / `print.css`

## Данные и БД
- [ ] После отправки формы или действия данные корректно сохраняются в БД
- [ ] Пользователю выводится понятное флеш-уведомление об успехе или ошибке
- [ ] Все SQL-запросы находятся только в `src/Models/` и используют PDO с подготовленными выражениями
- [ ] Операции, меняющие несколько таблиц или связанных записей, выполняются в транзакции (целиком или с откатом)

## Безопасность
- [ ] Вывод всех динамических данных во Views экранирован через `e()`
- [ ] Каждая POST-форма содержит `<?= csrfField() ?>`, **и** контроллер проверяет `requireCsrf()` / `verifyCsrfToken()` до чтения/изменения состояния
- [ ] Ресурсоёмкие POST-действия (запуск, повтор, перезапуск ИИ) ограничены атомарным `takeRateLimitAttempt()` без гонок
- [ ] Cookie сессии и заголовки безопасности не переопределены вручную в контроллерах (настроены в `ensureSessionStarted()` и `sendSecurityHeaders()`)
- [ ] Секреты и ключи API читаются только из `.env` и не попадают в HTML, JSON, PDF, URL или `storage/logs/app.log`
- [ ] Внешние URL/редиректы проверены `UrlValidator`; браузерные сценарии не отправляют реальные заказы и не совершают необратимых внешних действий

## Формы и валидация
- [ ] Пустые и некорректные входные данные отклоняются на сервере с понятной ошибкой без создания лишних записей и без запуска воркера
- [ ] Ошибочные параметры в URL (`id`, `version`, `a`/`b` и т. п.) ведут к понятному флешу и безопасному redirect без частичного рендера

## Код и проверки
- [ ] Нет ошибок в консоли браузера и упавших локальных ресурсов
- [ ] Нет новых PHP errors и warnings в `storage/logs/app.log` (кроме ожидаемых записей при проверке ошибок/лимитов без утечки секретов)
- [ ] Нет SQL в Controllers и Views, нет мёртвого кода и временных файлов от проверок
- [ ] Полный прогон PHPUnit проходит на PHP 8.3 OpenServer (`& "C:\OSPanel\modules\PHP-8.3\PHP\php.exe" vendor/bin/phpunit`)
