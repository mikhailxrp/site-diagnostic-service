## Таск 5 — Фоновое выполнение диагностики

**Статус:** ⏳ Ожидает

**Цель таска:**
Диагностику можно поставить в очередь, она выполняется отдельным процессом PHP по шагам и пишет статус каждого шага в БД. Упавший шаг не роняет всю диагностику.

**Что нужно создать/изменить:**
- `database/install.php` — таблицы `diagnostics`, `diagnostic_steps`
- `src/Models/DiagnosticModel.php` — создать, обновить статус / прогресс / heartbeat, получить с шагами
- `src/Services/JobLauncher.php` — запуск `bin/worker.php <id>` в фоне (`start /B` на Windows, `PHP_CLI_PATH` из `.env`)
- `src/Services/DiagnosticRunner.php` — список шагов, выполнение по порядку, try/catch на шаг, статусы `done / skipped / failed`
- `bin/worker.php` — CLI-точка входа воркера, без HTTP-контекста
- `tests/Unit/DiagnosticRunnerTest.php` — порядок шагов, расчёт прогресса, падение одного шага

**Definition of Done:**
- [ ] Запуск из веба возвращает ответ сразу, воркер продолжает работать после закрытия вкладки
- [ ] Шаги-заглушки выполняются по очереди, `diagnostics.progress` растёт до 100, статус → `done`
- [ ] Исключение в шаге: шаг `failed` с сообщением, остальные выполняются, ошибка в логе
- [ ] Диагностика без heartbeat дольше 10 минут при открытии помечается `failed` («прервана»)
- [ ] Повторный запуск воркера для `running`/`done` диагностики ничего не делает
- [ ] Проверить `.docs/dod-global.md`
