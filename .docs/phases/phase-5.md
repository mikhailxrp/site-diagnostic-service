## Цель
Владелец выгружает полный или клиентский отчёт в PDF, повторяет диагностику и видит, что исправлено и что появилось; сервис проверяет сценарий «товар → корзина → оформление» и открытые служебные файлы.

## Таск 1 — Сценарий «товар → корзина → оформление»

**Статус:** ⏳ Ожидает

**Цель таска:**
Шаг `checkout`: в браузере открыть товар, нажать «В корзину», перейти в корзину и к форме оформления. Заказ **не отправляется**. В отчёте — на каком шаге сломалось и что было в консоли.

**Что нужно создать/изменить:**
- `data/checkout-selectors.php` — селекторы кнопок и форм по CMS + общие текстовые шаблоны («В корзину», «Оформить»)
- `src/Services/CheckoutScenario.php` — шаги с тайм-аутами, скриншот на каждом шаге, запрет отправки формы оформления и любых POST после корзины
- `src/Services/Checks/CheckoutCheck.php` — находка `checkout` с номером упавшего шага
- `src/Views/components/checkout-steps.php`

**Definition of Done:**
- [ ] На тестовом магазине доходит до формы оформления, заказ не создаётся (проверено в админке тестового магазина)
- [ ] Не найдена кнопка / товар не добавился / форма не открылась — каждый случай даёт свою находку со скриншотом
- [ ] Товар без наличия или с вариантами → шаг `skipped` с причиной, а не «сломано»
- [ ] Проверить `.docs/dod-global.md`

## Таск 2 — Открытые служебные файлы

**Статус:** ⏳ Ожидает

**Цель таска:**
Шаг `exposed_files`: проверка по фиксированному списку (`.git/HEAD`, `.env`, бэкапы и дампы, `phpinfo.php`, логи) без скачивания содержимого целиком.

**Что нужно создать/изменить:**
- `data/exposed-files.php` — список путей и признак содержимого для каждого (чтобы отличить настоящий файл от «мягкого 404»)
- `src/Services/Checks/ExposedFilesCheck.php` — GET с ограничением размера ответа, проверка признака
- `tests/Unit/ExposedFilesCheckTest.php`

**Definition of Done:**
- [ ] Сайт, отдающий 200 с главной на любой адрес, не даёт ложных находок (тест)
- [ ] Открытый `.env` / `.git` → находка `critical`; в отчёт не попадают значения секретов, только факт доступности
- [ ] Читается не больше N КБ каждого файла (константа)
- [ ] Проверить `.docs/dod-global.md`

**Цель таска:**

- [ ] Без Chrome — понятное сообщение, а не пустой файл
