## Решения, принятые при планировании

| Решение | Почему |
|---|---|
| Все экраны собираются из стандартных компонентов Tabler, без образцов и своих стилей; публичной части нет (решение владельца, 15.11.2026) | сервис только для владельца; Tabler даёт готовые формы, таблицы, прогресс |
| Tabler 1.6.1 + Tabler Icons 3.52.0 лежат в `public/assets/vendor/tabler/` (см. `VERSION.md` там же) | скачаны из npm 15.11.2026 |
| Форма новой диагностики — на главной `/`; шага-заглушки «Сборка отчёта» нет, отчёт собирается из БД при открытии (решение владельца, 15.11.2026) | меню уже ведёт на `/`; отдельный шаг не нужен |
| Ключи API (`ROUTERAI_API_KEY`, `PAGESPEED_API_KEY`, `WPSCAN_API_KEY`) и `ROUTERAI_BASE_URL` хранятся в `.env`, не в БД; страница настроек показывает их маской, только для чтения (решение владельца, 15.11.2026) | правило CLAUDE.md «секреты только в .env» |
| Base URL RouterAI: `https://routerai.ru/api/v1` | указан владельцем в `.env` |
| Лимитов обхода нет: ни в настройках, ни в коде нет числа страниц и паузы между запросами. Добавим, когда упрёмся (решение владельца, 15.11.2026). Технические тайм-ауты curl / Chrome остаются именованными константами в коде | без тайм-аута зависший сайт подвесит воркер |
| Входа нет: ни пароля, ни таблицы `users`, ни страницы входа (решение владельца, 15.11.2026). CSRF на POST-формах остаётся; сайт отвечает только с этого ПК (`Require local`, если OpenServer слушает не только `127.0.0.1`) | пользователь один; CSRF защищает от чужих сайтов, открытых в том же браузере |
| Фон: CLI-воркер `bin/worker.php`, запускается из веба через `start /B` (Windows), прогресс — опрос JSON раз в 2 с | OpenServer на Windows, без очередей и демонов |
| HTTP — curl, разбор HTML — `DOMDocument` | встроено в PHP, без пакетов |
| Браузер — `chrome-php/chrome` (Composer) | PRD; запрет касается только пакетов роутинга/DI |
| PDF — печать страницы отчёта через тот же Chrome (`printToPDF`) | не нужна вторая библиотека |
| Сигнатуры CMS и справочник версий — файлы в `data/` (PHP-массивы / JSON) | легко пополнять без кода |
| ИИ-находка без валидной ссылки на факты отбрасывается | главный принцип PRD |
