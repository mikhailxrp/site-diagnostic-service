## Таск 1 — Поиск ключевых страниц магазина

**Статус:** ⏳ Ожидает

**Цель таска:**
Шаг `crawl` находит категорию, товар, корзину и оформление: по типовым адресам найденной CMS, по ссылкам и кнопкам на страницах, либо по адресу товара, указанному вручную.

**Что нужно создать/изменить:**
- `data/shop-patterns.php` — типовые адреса корзины/оформления и признаки ссылок на категории/товары по CMS
- `src/Services/ShopCrawler.php` — главная → категория → товар; корзина и оформление по шаблонам; по одной странице каждого типа (это цель обхода, а не лимит)
- `src/Views/diagnostics/create.php` — необязательное поле «адрес товара»
- `src/Models/PageModel.php` — тип страницы, `found_by`
- `tests/Unit/ShopCrawlerTest.php` — на фикстурах

**Definition of Done:**
- [ ] Для каждой из CMS списка на фикстурах находятся категория и товар
- [ ] Указанный вручную товар используется вместо автоматического поиска
- [ ] Не найденная страница отмечается в отчёте «не найдена», а не молча пропускается
- [ ] Обход идёт только по ссылкам своего домена и останавливается, когда найдены все типы страниц
- [ ] Проверить `.docs/dod-global.md`

## Таск 2 — Проверки на всех найденных страницах и защита от ботов

**Статус:** ⏳ Ожидает

**Цель таска:**
Проверки ресурсов и PHP-ошибок из фазы 1 идут по каждой найденной странице; сайты за Cloudflare / капчей отмечаются «не удалось проверить».

**Что нужно создать/изменить:**
- `src/Services/DiagnosticRunner.php` — шаг `resources` по всем страницам, общий кэш проверенных ресурсов
- `src/Services/Checks/BotProtectionCheck.php` — признаки Cloudflare challenge, DDoS-Guard, капчи
- `src/Models/PageModel.php` — флаг `blocked`
- `src/Views/diagnostics/report.php` — находки сгруппированы ещё и по страницам
- `tests/Unit/BotProtectionCheckTest.php`

**Definition of Done:**
- [ ] Один и тот же битый ресурс на 3 страницах — одна находка со списком страниц
- [ ] Страница-заглушка Cloudflare даёт `blocked = 1` и пометку в отчёте, без ложных находок
- [ ] Проверить `.docs/dod-global.md`

## Таск 3 — Устаревшие версии и уязвимости

**Статус:** ⏳ Ожидает

**Цель таска:**
Для найденных версий CMS, плагинов и JS-библиотек показывается актуальная версия и известные уязвимости.

**Что нужно создать/изменить:**
- `data/latest-versions.json` — актуальные версии (CMS, jQuery и др.), дата обновления справочника
- `data/vulnerabilities/*.json` — свой список по Битрикс / OpenCart и др.
- `src/Services/VulnerabilityService.php` — сравнение версий (`version_compare`), источник из настроек (WPScan API для WordPress — если выбран)
- `src/Services/Checks/OutdatedCheck.php` — находки `outdated` и `vulnerability` со ссылкой на элемент стека
- `tests/Unit/VulnerabilityServiceTest.php`

**Definition of Done:**
- [ ] jQuery 1.x даёт находку «устарело» с текущей версией из справочника
- [ ] Уязвимость содержит идентификатор (CVE / источник) и диапазон затронутых версий
- [ ] Без версии находка не создаётся (только «версию определить не удалось»)
- [ ] Отказ внешнего API не роняет шаг, используется локальный список
- [ ] Проверить `.docs/dod-global.md`

## Таск 4 — Базовое SEO

**Статус:** ⏳ Ожидает

**Цель таска:**
Шаг `seo`: robots.txt, sitemap.xml, title / description, canonical, noindex / nofollow на проверенных страницах.

**Что нужно создать/изменить:**
- `src/Services/Checks/SeoCheck.php` — наличие и доступность robots/sitemap, `Disallow: /` для всех, мета и canonical по страницам, `X-Robots-Tag`
- `src/Views/diagnostics/report.php` — блок SEO
- `tests/Unit/SeoCheckTest.php`

**Definition of Done:**
- [ ] `noindex` на главной или `Disallow: /` → находка `high`
- [ ] Пустой / одинаковый title на разных страницах → находка `low`
- [ ] Проверить `.docs/dod-global.md`
